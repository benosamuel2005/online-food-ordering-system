# Online Food Ordering System — Python

An academic software engineering project developed using Python as part of my BSc (Honours) in Computing at Dublin Business School.

## Project Overview

This project explores the development of an online food ordering system using object-oriented programming principles.

The repository contains Python application code and a separate unit testing file, demonstrating software development and testing practices.

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Python unittest
- Software Engineering Principles

## Project Files

- `order.py` — Main application code
- `test_order.py` — Unit tests for the ordering system

## Skills Demonstrated

- Python Programming
- Object-Oriented Design
- Input Validation
- Unit Testing
- Software Testing and Debugging
- Code Organisation

## Running the Project

Ensure Python 3 is installed.

To run the application:

```bash
python3 order.py
```

To run the unit tests:

```bash
python3 -m unittest test_order.py
```
